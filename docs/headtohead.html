How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one family safety and location-tracking app, Life360 or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total), via the OpenAI API (gpt-4o) directly, with a system prompt forcing a decisive pick.
  • Open comparison question: "Life360 vs. {rival}: which should I choose?" Asked once per order (12 answers), no system prompt — this is where the qualitative reasoning below comes from. It is not repeated, so a single odd answer could be noise. The API route has no browsing, so none of these answers carry citations — they're the model's general knowledge, not a sourced comparison.
  • Both orders are asked because the model can lean toward whichever brand is named first. For FamiSafe, GeoZilla and Find My Kids it doesn't matter — Life360 sweeps 10 of 10 either way. For Bark, Qustodio and Google Family Link there's a mild lean, with Life360 still winning the large majority (8–9 of 10) in both orders.
  • The headline finding: this isn't a close contest, but it's also not a simple "Life360 is better" story. The model almost always frames each rival as solving a different problem (digital/screen-time monitoring vs. physical location and driving safety) rather than declaring Life360 superior at the rival's own specialty — Google Family Link in particular keeps its free, Google-integrated edge even while losing the forced pick.
  • Not yet covered: pricing, integrations, onboarding, setup and support as separate scored dimensions — they'd need their own repeated, structured prompts to be real rather than invented. Also not covered: any run through the ChatGPT web app, and any run while logged in.
